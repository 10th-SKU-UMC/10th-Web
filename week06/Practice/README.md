---

## 초기 세팅

### 패키지 설치

```bash
pnpm install
```

### 개발 서버 실행

```bash
pnpm run dev
```

---

## 환경 변수 설정

프로젝트 루트 디렉토리에 `.env` 파일을 생성한 뒤 아래 내용을 추가하세요.

```env
VITE_TMDB_KEY=your_token_here
VITE_SERVER_URL=http://localhost:8000
```

### `.env.example`

```env
VITE_TMDB_KEY=your_token_here
VITE_SERVER_URL=http://localhost:8000
```
